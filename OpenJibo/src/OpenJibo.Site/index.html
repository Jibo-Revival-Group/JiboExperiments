Robot Launch Rules

Owners can register their robot's friendly name and upload custom .rule launch files through the public launch-rules page. Those files are stored per robot on the OpenJibo cloud.

Current Direction

The first milestone is a stable Azure-hosted replacement cloud. We support real robots first through controlled DNS plus targeted device patching, then smooth the path later with OTA.
